## Traced model and premise

Research capability adapters call canonical profile/assessment/reference owners and wrap their DTOs. Owners persist arbitrary profile/reference freeform text or generated assessment snapshots without ContentPolicy. Profile reads filter visible evidence but return the remaining text. Assessments compare a current fingerprint for stale status, yet return historical result_json unless Vault excerpts become invisible. Reference views embed assessment DTOs. Generic cache capture reconstructs a subset of guards by looking at top-level properties, which omits nested content and is not a domain contract.

Managed file storage policy describes the contribution's derivation. Source observation also adds current document/folder obligations and exact version/digest. Passing only storage policy to delivery discards the reader's access constraints. Inferring disclosure from source visibility grants another person's sharing authority. An explicit own-original exception is different from merely seeing the file.

Settings have retained policies in storage, but a plain getter DTO drops them before capability parsing/provenance. A later private artifact knows uncertainty but has forgotten known revocation guards.

Provider preparation and dispatch are separated by real async waits. A transaction before staging protects only that transaction. Runtime admission must happen after staging/configuration/reservation waits, at the actual dispatch boundary. Post-generation rejection cannot undo disclosure.

The repeated failed premise is that adapters can reconstruct complete provenance from selected result fields, or that an earlier authorization covers later awaited dispatch. The bounded rerunnable census .audit/lume-source-round3-census.mts/.json records where ownership currently lives. Its counts are call-site evidence, not a vulnerability/completeness scanner.
