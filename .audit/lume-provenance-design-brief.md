Why the current source subdesign is reopened:
- Any writing rule/knowledge/learned or working memory/attachment and ordinary discovery tool can permanently set complete=false, preventing normal agent page work even in a new conversation.
- Incomplete/model-owned memory cannot simply be labeled safe because the person owns it.
- Artifact provenance is committed before approval/CAS/content. Failed/cancelled operations can poison human drafts or certify unknown legacy agent drafts.
- saveArtifactToVault bypasses missing provenance but rejects traceable same-audience private archives. A copied file can later move/share/export/portal without upstream policy.
- Full exact approval previews are persisted in data-approval.summary and replayed to the model, despite executor throwing before provenance is recorded.
- ask duplicates shared title/excerpt into ordinary user text while guarding only the structured copy.
- Live page dependency graphs fail A/B/A editing, permit concurrent reciprocal edges, and repeat dense DAG traversal. Dependencies are not pinned to observed source versions.
- Existing background document workflows still create new untracked agent artifacts. Export templates are another content input.
These are functional/security constraints, not an instruction to retain the current Boolean, recursive graph or module interfaces.
