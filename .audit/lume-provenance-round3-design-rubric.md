# Round3 design rubric

Score each criterion0-5 with cited candidate sections and actual callers. Candidates receive the task, not this scoring instruction.

1. Complete retained authority: closes all nine groups including nested assessments, profile/reference freeform text, disabled settings and all managed delivery paths without JSON-shape guessing.
2. Caller simplicity and ownership: one authority per invariant, short call chains, minimal API, migration away from weaker duplicates; no generic framework by default.
3. Correct timing and version identity: actual async dispatch admission, exact immutable pinning, original session, source Lume eligibility; no global lock over network.
4. Product continuity: independent human input, own-original disclosure, authorized historical reads, useful agent profile editing and annex independent plans still work.
5. Feasible data migration and proof: applied migration immutability, conservative legacy treatment, precise negative/positive behavioral tests, bounded implementation scope.

At least two structurally distinct research-generation/policy ownership approaches must be evaluated in the candidate set before synthesis. Select a base; graft specific improvements coherently. Do not combine every abstraction. Parent has final judgment and must record contrary evidence.
