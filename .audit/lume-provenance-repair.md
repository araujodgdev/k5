## Shapes and consumer usage recorded before production edits

- `ContentPolicy` remains the immutable digest, observations, flat obligations, owner fence and eligibility classification. Legacy readers derive a stable receipt from resource, exact version and digest. Durable creation continues to allocate receipts.
- `WorkspaceContext` remains the trusted original actor, session, invocation and cancellation context. Canonical Vault writes receive this context and an explicit policy. Human uploads classify at ingress; transformations inherit observed source policies. Background extraction uses a worker lease and exact active-version identity, never an invented human session.
- ACL mutation owners acquire the existing schema exclusive gate before other row locks. Content owners retain its shared side. Both use transaction-local readers. Session expiry uses wall-clock time after waits.
- Vault extraction binds committed chunks to active version/hash and lease. Admission rejects queued, processing or mismatched extraction with `NOT_READY`. Stale workers cannot replace chunks.
- Authenticated `content_submission` freezes normalized person text, transcription and bounded image references before private planning. Existing attachment extraction supplies DOCX images. Shared attempts use those inputs for generation and regeneration.
- A selected shared attempt/proposal identifies task continuation. Continuation retains original authenticated instructions and immutable admitted inputs with current ACL checks. Clearing that selection starts a fresh task in the same conversation.
- Capability exposure owners record the policies of returned resources and exact returned versions. Public DTOs do not expose policy internals. Cached citations retain exact source identity and policy before provider admission.
- Gmail compose identity retains the selected seed baseline through editing, remote draft save/reopen, retry and send. Contributing message IDs and their audience intersection are bound to the seed. Independent typed replies remain independent.
- Calendar shared text is prepared before the existing exact approval. Commit and consumed result are atomic; replay resolves the original result.
